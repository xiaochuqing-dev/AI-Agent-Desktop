产品范围固定

产品仍是面向 Windows 开发者的 Telegram AI 编程团队安装、配置、管理、诊断与恢复中心。首发仅 Windows 10/11 与 Telegram；Agent 固定为 Hermes、Claude Code、Codex；cc-connect 是 V1 核心桥梁；CC Switch 是推荐但非强制入口。不得扩展 Agent、Channel 或通用平台能力。

准确限制

整体阶段为 PARTIAL。真实 Telegram 为 PENDING USER LIVE VALIDATION；Windows 10 为 PENDING WINDOWS 10 VALIDATION；Hermes 为 pending_component_install。锁定上游 management API 无 bind host 字段，实测监听所有网卡；原生 Telegram options 无 Group Chat ID 白名单；deep health 无官方端点，这三项不得虚报，且不得为此增加 Patch。Python/keyring 无法保证物理内存完全清零。
