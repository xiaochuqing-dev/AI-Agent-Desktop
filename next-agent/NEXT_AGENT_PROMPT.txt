产品范围固定

产品仍是面向 Windows 开发者的 Telegram AI 编程团队安装、配置、管理、诊断与恢复中心。首发仅 Windows 10/11 与 Telegram；Agent 固定为 Hermes、Claude Code、Codex；cc-connect 是 V1 核心桥梁；CC Switch 是推荐但非强制入口。不得扩展 Agent、Channel 或通用平台能力。

已交付事实

Control Plane 已有 loopback + Bearer、7 个只读 Adapter、Readiness、DryRun、Diagnostic、持久化 OperationExecutor/SSE 和 Alembic。cc-connect Windows amd64 锁定基线为 fc315d213b49d62e9d90ea4a510189d4115e636f + Patchset 0.1 + Go 1.26.5，产物 SHA256 为 cd1b0787709c0401a42f7c3ce5321184889adbfbf3b080190fee180afc977eec。

仅针对产品自有 cc-connect，已实现隔离安装、不可变配置计划、显式确认、原子最小配置、revision/备份/回滚、SecretRef/CredentialBackend 边界、ManagementOwner/LifecycleOwner 交接、start/stop/restart/status/reconcile、PID 复用与 exe SHA 验证、端口所有权、崩溃与 Control Plane 重启恢复。更新与 ExternalToolProvider 稳定边界已存在，但不执行自动更新。CC Switch 只检测公开可执行入口并普通打开。

准确限制

锁定版 cc-connect 要求至少一个 Project 和 Platform；Telegram-disabled、无 Secret 合成配置无法满足运行前提，且上游无稳定本地 health endpoint。因此无 Secret 真实持续运行验收是 PARTIAL，local endpoint/deep health 是 unsupported。Windows 10 x64 是 pending user real-machine validation。Windows Credential Manager 适配器只有不读写 Secret 的骨架。Reference Baseline、真实配置、计划任务、Watchdog、注册表、系统 PATH 和外部进程未修改。
